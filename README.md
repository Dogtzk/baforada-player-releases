# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.40](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.40/BafoPlayer-Setup-1.8.40.exe)

[Baixar APK Android 1.6.35](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.40/BafoPlayer-Android-1.6.35.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Novo tema Femtanyl com cinco variações e cinco imagens escolhidas por vocês: Token monocromático, A Minute rosa, CRT azul, Redline vermelho e Afterimage azul-violeta. Cores, botões, ícones e enquadramento combinam com cada arte. Disponível no PC e no Android. Android mantém somente o volume de mídia do celular, sem uma segunda barra no app. Biblioteca, conta, temas personalizados e downloads preservados.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
