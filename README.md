# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.45](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.45/BafoPlayer-Setup-1.8.45.exe)

[Baixar APK Android 1.6.40](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.45/BafoPlayer-Android-1.6.40.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Novo tema Hatsune Miku com cinco variações: Clássica, Sakura, Snow Miku, New Type e Palco. Cada uma tem arte, cores e ícones próprios, com layout adaptado para PC e Android. As artes completas permanecem visíveis e os fundos são estáticos, sem animações contínuas. Disponível em Temas → Hatsune Miku. Inclui Android 1.6.40.

Artes: KEI / iXima; Hatsune Miku © Crypton Future Media, INC. Créditos e fontes incluídos no aplicativo.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
