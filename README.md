# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.52](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.52/BafoPlayer-Setup-1.8.52.exe)

[Baixar APK Android 1.6.47](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.52/BafoPlayer-Android-1.6.47.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Fila completa de reprodução: as músicas da seleção aparecem juntas, com sequência estável também no aleatório. O inteligente preserva as faixas já previstas e acrescenta sugestões parecidas ao final. A sequência é mantida ao fechar e reabrir o app. Filas grandes exibem mais itens conforme você rola, sem baixar todos os áudios de uma vez. No Android, corrigida a prioridade dos arquivos baixados no modo offline, com busca do arquivo também pela identidade da faixa. Quando uma fonte personalizada falha, o download existente é usado como alternativa. O modo offline não procura uma fonte online quando o arquivo não está disponível no aparelho. Windows 1.8.52 e Android 1.6.47.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
