# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.48](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.48/BafoPlayer-Setup-1.8.48.exe)

[Baixar APK Android 1.6.43](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.48/BafoPlayer-Android-1.6.43.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Busca por músicas do mesmo estilo mais rápida no PC e Android. As consultas independentes começam juntas; a tela carrega até duas seções em paralelo e mostra resultados parciais. Sugestões já obtidas são reaproveitadas e chamadas iguais compartilham a mesma busca. Uma resposta vazia deixa de ficar guardada por 30 minutos. Requisições demoradas têm limite de espera e liberam a fila. A identificação do estilo mantém os filtros contra gêneros sem relação. Inclui Android 1.6.43.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
