# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.49](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.49/BafoPlayer-Setup-1.8.49.exe)

[Baixar APK Android 1.6.44](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.49/BafoPlayer-Android-1.6.44.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Novo tema Yung Lixo com as quatro imagens enviadas e quatro variações: Sucesso FM, Validation Rádio, Memórias FM e Refúgio FM. Cada opção tem cores e ícones próprios, com arte inteira e layout adaptado para PC e Android. Fundos estáticos, sem animações contínuas. O seletor mostra a quantidade real de variações de cada tema. Disponível em Temas → Yung Lixo. Inclui Android 1.6.44.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
