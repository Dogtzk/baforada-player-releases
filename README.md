# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.47](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.47/BafoPlayer-Setup-1.8.47.exe)

[Baixar APK Android 1.6.42](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.47/BafoPlayer-Android-1.6.42.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Correções da transição gradual no Windows e Android. A troca automática confere novamente o ponto real da música após carregamentos e limita a mistura ao trecho final configurado. Voltar o tempo durante um carregamento cancela a troca antecipada. A faixa anterior continua na mistura até terminar; se já terminou, a próxima entra com volume normal. No Android, pausas e buffering congelam o relógio da transição, e a retomada mantém as duas faixas da mistura. Inclui Android 1.6.42.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
