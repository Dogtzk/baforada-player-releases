# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.39](https://github.com/Dogtzk/baforada-player-releases/releases/download/android-v1.6.34/BafoPlayer-Setup-1.8.39.exe)

[Baixar APK Android 1.6.34](https://github.com/Dogtzk/baforada-player-releases/releases/download/android-v1.6.34/BafoPlayer-Android-1.6.34.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Android 1.6.34: o volume agora é controlado somente pelos botões de mídia do celular. Removida a segunda barra de volume do app em telas verticais e horizontais; níveis antigos salvos no player não reduzem mais o áudio. O volume de mídia escolhido no Android é preservado. Windows 1.8.39 permanece sem alterações. O tema Femtanyl continua em rascunho e não está incluído nesta publicação.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
