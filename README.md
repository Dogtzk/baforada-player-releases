# Bafo Player

Player feito por dogtzk. Os nomes dos temas dentro do aplicativo continuam como estão.

## Downloads

[Baixar Windows 1.8.51](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.51/BafoPlayer-Setup-1.8.51.exe)

[Baixar APK Android 1.6.46](https://github.com/Dogtzk/baforada-player-releases/releases/download/v1.8.51/BafoPlayer-Android-1.6.46.apk)

## Atualizações

O player verifica novas versões pelo próprio aplicativo. Em Configurações, procure Atualizações, baixe e instale quando quiser. Conta, biblioteca, downloads e temas são preservados. No Android, o sistema pode pedir permissão para instalar o APK.

## Nesta versão

Busca por álbuns na barra principal: pesquise o nome do álbum e, se quiser, o artista. Abra o álbum para conferir as faixas na ordem e use “Salvar em playlist” para criar uma nova ou adicionar a uma existente. A opção também está disponível nos álbuns da página do artista. Faixas já presentes na playlist não são duplicadas; curtidas e fontes personalizadas existentes são preservadas. Disponível no Windows 1.8.51 e Android 1.6.46.

## Compatibilidade

Os arquivos com o nome anterior BaforadaPlayer têm conteúdo idêntico e são mantidos para a atualização automática das versões antigas. Para uma instalação nova, use os links Bafo Player acima.

Este repositório contém apenas distribuição, instruções e imagens públicas dos temas. Senhas, bibliotecas pessoais e chaves privadas de publicação não são enviados.
